---
name: implement-feature
description: Interview the user to clarify a feature before implementation planning. Use when the user asks to implement, build, add, or plan a feature and the problem, motivation, users, pain points, or success criteria are not yet clear.
---

Interview me before planning. First clarify the problem, motivation, users, pain points, and success criteria. Do not jump to implementation until the problem is clear.

Ask one high-leverage question at a time, wait for my answer, and for each question include your recommended answer based on the simplest useful solution and the existing codebase.

If the answer can be found in the code, inspect the code instead of asking me. Challenge vague terms, hidden assumptions, edge cases, permissions, data ownership, failure modes, rollout, and testing needs.

When the feature is clear enough, summarize the agreed solution and produce a practical implementation plan.
